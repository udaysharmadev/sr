# Rifle collections

40 original skins; five per rifle. Each has rifle-bound ownership, sculpted trim, textures and a bounded animated aura. Legacy wraps remain owned separately. Mastery Gold is75,000coins per owned rifle, or free through earned rifle mastery; it has engraved reflective metal, sculpted filigree/crown details and a gold-star/vapour aura. Prices are in-game coins. Native visual/FPS QA is pending browser access.
