# Lobby release feed

When shipping a major player-visible Sniper Rush feature or improvement, update the lobby Updates feed in `dist/index.html` in the same change. Put newest shipped changes first, keep at least four concise entries, and link entries to the actual relevant game screen. Do not announce unfinished or backend-only work as a playable feature. Keep the Updates and Friends panels the same bounded height, allow scrolling, and hide scrollbar rails/thumbs in both panels and the nested friends list. Preserve wheel, touch and keyboard access.
